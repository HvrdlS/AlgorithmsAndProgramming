Дано: P > 0 - початкова сума вкладу;
r >= 0 - річна процентна ставка у відсотках.

Знайти: A - сума вкладу через один рік.

Модель: A = P(1 + r/100)

Алгоритм:
1. Ввести початкову суму P.
2. Ввести річну процентну ставку r.
3. Перевести ставку з відсотків у десятковий вигляд r/100.
4. Обчислити суму A = P(1 + r/100).
5. Вивести A.
6. Кінець.

Тести:
P = 1000, r = 10 - A = 1100
P = 5000, r = 0 - A = 5000
P = 0.01, r = 100 - A = 0.02
