Дано: p > 0 - ціна одиниці товару;
n > 0 - кількість товару;
d - знижка у відсотках, 0 <= d <= 100.

Знайти: C - кінцеву вартість покупки.

Модель: Вартість без знижки: C0 = pn; Розмір знижки: D = C0*d/100; Кінцева вартість: C = C0 - D або: C = pn(1 - d/100)

Алгоритм:
1. Ввести ціну одиниці товару p.
2. Ввести кількість товару n.
3. Ввести розмір знижки d.
4. Обчислити початкову вартість C0 = pn.
5. Обчислити кінцеву вартість C = C0*(1 - d/100).
6. Вивести C.
7. Кінець.

Тести:
p = 100, n = 3, d = 10 - C = 270
p = 50, n = 1, d = 0 - C = 50
p = 1000, n = 100, d = 100 - C = 0 - крайній випадок, знижка 100%.
