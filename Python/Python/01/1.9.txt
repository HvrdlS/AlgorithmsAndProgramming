Дано: a > 0, b > 0, c > 0 - довжини сторін трикутника.

Обмеження: сторони повинні задовольняти нерівності трикутника:
a + b > c
a + c > b
b + c > a

Знайти: S - площу трикутника.

Модель: S = sqrt(p(p - a)(p - b)(p - c)),

Алгоритм:
1. Ввести a.
2. Ввести b.
3. Ввести c.
4. Перевірити виконання нерівностей трикутника.
5. Якщо хоча б одна нерівність не виконується, вхідні дані є некоректними.
6. Обчислити півпериметр p = (a + b + c)/2.
7. Обчислити площу S = sqrt(p(p-a)(p-b)(p-c)).
8. Вивести S.
9. Кінець.

Тести:
(3, 4, 5) - S = 6
(1, 1, 1) - S = 0.433
(1, 2, 2.999) - S = 0.0316 - крайній допустимий випадок.
