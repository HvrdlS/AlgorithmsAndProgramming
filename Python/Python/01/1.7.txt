Дано: v >= 0 - швидкість автомобіля в км/год;
t >= 0 - час руху в годинах;
q >= 0 - витрата палива в літрах на 100 км.

Знайти: s - пройдений шлях у кілометрах; Q - витрачену кількість палива в літрах.

Модель: s = vt; Q = sq / 100

Алгоритм:
1. Ввести швидкість v.
2. Ввести час руху t.
3. Ввести витрату палива q.
4. Обчислити шлях s = vt.
5. Обчислити витрату палива Q = sq / 100.
6. Вивести s і Q.
7. Кінець.

Тести:
v = 60, t = 2, q = 8 - s = 120 км, Q = 9.6 л
v = 0, t = 5, q = 10 - s = 0 км, Q = 0 л
v = 200, t = 10, q = 20 - s = 2000 км, Q = 400 л
