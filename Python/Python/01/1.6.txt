Дано: x1, y1, x2, y2 - координати двох точок площини, дійсні числа.

Знайти: d - відстань між точками.

Модель: d = sqrt((x2 - x1)^2 + (y2 - y1)^2)

Алгоритм:
1. Ввести x₁.
2. Ввести y₁.
3. Ввести x₂.
4. Ввести y₂.
5. Обчислити різниці координат dx = x2 - x1 та dy = y2 - y1.
6. Обчислити відстань d = sqrt(dx^2 + dy^2).
7. Вивести d.
8. Кінець.

Тести:
(0, 0), (3, 4) - d = 5
(1, 1), (1, 1) - d = 0
(-100, -100), (100, 100) - d = 282.843
